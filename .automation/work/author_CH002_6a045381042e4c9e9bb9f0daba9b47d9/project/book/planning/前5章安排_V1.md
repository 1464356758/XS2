# 前5章安排｜V1

这是未来计划，不是正文、写作任务已开始或发布前审核结果。每章预算9000汉字，实际全文生成后另行计数和审查。

## CH001《锅炉是冷的，龙也是》

故事时间：D0 08:00—21:00；整数刻度0—780。

主要改变：陌生领主、住户与老龙形成一次有界的合作，第一间60人暖屋获得实际热量。

主动选择与代价：放弃领主专属暖位和部分私人用途材料，以付出可信代价换合作，接受赫穆有权拒绝。

核心压力：旧炉不能启动，住房容量与接收容量分开；冷天里没有时间先建立大家的信任。

开场要求：800汉字内见到冷炉与拒绝被命令的龙；3000汉字内出现有限供暖交涉及对伊恩本人处境的影响。此为编辑策略，不冒称平台规定。

| 场景 | 汉字预算 | 场景作用 |
|---|---:|---|
| 1·进堡与冷炉 | 1000 | 让主角先面对人和旧炉，龙在首场出现；现代来历压缩到理解本场所需。 |
| 2·不能开的那一座 | 1400 | 由本地经验与可见缺陷建立停用边界，伊恩放弃逞能。 |
| 3·先问龙要什么 | 1700 | 赫穆提出干燥、安静、拒绝强迫和可离开的需要；协商有分歧与性格。 |
| 4·谁先让出地方 | 1500 | 诺拉提出住户实际需求；伊恩拿自己的便利作代价，不许别人替他慷慨。 |
| 5·第一团可用的热 | 2000 | 按安全接收能力控制短息，点火与受益实际呈现，不输出真实改造步骤。 |
| 6·六十个人的夜里 | 1400 | 用热汤和具体住户反应兑现暖意，同时交代其余人仍依赖分散小灶。 |

预算合计：9000汉字。

气味、动作与语气：冷手重新发痛、漏风与龙挑剔人类小门的克制幽默；暖意先落在人，不是参数。

硬边界：旧封闭炉停用；不把两暖格直接写成120人的住房；只算已实际得到的热；初始库存仍需角色实盘；第一章主要具名人物不超过四人。

采用前应查的证据：正文应有真实点火、自愿条件、主角付出的资产/便利和第一批受益者；尚无正文，不填引文。

后续接续：CH002必须面对暖位不足，不能一句全城温暖抹去。

## CH002《第一把椅子给谁》

故事时间：D1 06:00—19:00；整数刻度1320—2100。

主要改变：配给与安置不再完全依熟人或领主偏好，形成有限但可执行的暖位安排。

主动选择与代价：接受诺拉按具体需求排位，即使自己的随行者不满意。

核心压力：可用房间只有60人容量，第二房间还缺场地和工时；食物与材料账面数需核实。

开场要求：以有人被挡在门外的具体冲突进入，不重述CH001所有协议。

| 场景 | 汉字预算 | 场景作用 |
|---|---:|---|
| 1·门口的第一把椅子 | 1200 | 从两个正当需要的冲突出发，避免把争暖位者都写成坏人。 |
| 2·把名字认全 | 1800 | 诺拉提供住户情况；角色只知道自己调查得到的信息。 |
| 3·领主的人也要等 | 1500 | 主角付出偏袒随行者会更方便的机会，护卫可表达不满。 |
| 4·粮房与料堆 | 1500 | 实际盘点进入行动与对话，不复制整张维护表；记录与实物差异如实留着。 |
| 5·乌铎的一个不字 | 1700 | 具名引入匠人，对不安全旧部件拒绝；不因主角身份立刻服从。 |
| 6·今晚的安排 | 1300 | 落实首日排位与扩建所需，部分人接受但不全员感激。 |

预算合计：9000汉字。

气味、动作与语气：椅子、湿毯与食物形成生活触感，气氛以人的尊严而非开会流程推进。

硬边界：盘点后才更新人物知道的库存；库存和口粮不能给访客重复计算；房间扩容未完成不能算新暖位；不得再用一次龙火自动解决公平问题。

采用前应查的证据：实际排位、受影响者选择与伊恩退让，角色新知须有取得途径。

后续接续：CH003既缺干柴又遇龙的休息，检验说好的拒绝权。

## CH003《龙今天不上工》

故事时间：D2 08:00—19:00；整数刻度2880—3540。

主要改变：不使用龙深息的一天也被人类合作撑住，技工获得真实报酬和拒工权。

主动选择与代价：先保烹饪与最低暖位，取消私人装点用料；向有经验的人让出现场判断。

核心压力：D2明确作为休息日，不能把D0/D1没用完的龙火额度存下来再吐。

开场要求：从赫穆拒绝被催醒、住户等火的现场进入，让幽默与焦虑并存。

| 场景 | 汉字预算 | 场景作用 |
|---|---:|---|
| 1·龙不需要上工的借口 | 1400 | 让拒绝本身有效，不靠新伤或病危才准休息。 |
| 2·同一堆柴 | 2000 | 厨房、住户与施工同时争料；伊恩必须说清牺牲哪项收益。 |
| 3·林边的路 | 2200 | 有限人数取材，天气与役畜决定能带回多少，不凭一句收集得到无限木料。 |
| 4·手艺要先有工钱 | 2000 | 用可支付的现金或经同意的实物结算，不许慷慨许诺全部未来。 |
| 5·不靠那口火的晚饭 | 1400 | 不是全城从此不用龙，而是一次有限、费力的独立支撑。 |

预算合计：9000汉字。

气味、动作与语气：人挪柴、分热汤，赫穆醒着评论人类，而不是一直当沉睡道具。

硬边界：D2深息量为零；干柴、工资与劳力在同一来源池扣减；护卫或役畜不能同时守堡和全员出林；不以新增能力渡过休息日。

采用前应查的证据：自愿拒绝有实际代价，劳动者真的收到可用报酬。

后续接续：已知白渡车队通常会到，CH004的遇险消息须由真实抵达者或亲见提供。

## CH004《断桥上的粮车》

故事时间：D3 05:00—21:00；整数刻度4140—5100。

主要改变：粮车、货主与一批实物真正进入城内，新增交易责任而不是免费获得全部粮。

主动选择与代价：拿有限运力救人和关键货物，另行承担采购和维修成本。

核心压力：断桥、队员安全、存粮紧迫与货物产权同时存在；不能所有东西都保住。

开场要求：以带明确来源的消息或到场观察进入，不让主角遥知桥塌与敌人位置。

| 场景 | 汉字预算 | 场景作用 |
|---|---:|---|
| 1·有人没有按时到 | 900 | 通过行程与抵达者获得问题，不额外讲一遍世界地图。 |
| 2·城里也得留下人 | 1500 | 塞恩安排留守与救运，主角不能带走全部有用角色。 |
| 3·桥前的货主 | 1800 | 货主有自己的货与损失，拒绝免费交粮是合理立场。 |
| 4·只能先救一边 | 2100 | 救人、牲口与货物的优先次序改变本次所得；不写现实危险救援操作教程。 |
| 5·把粮运进门 | 1400 | 行程、载荷、原主车辆和本城车辆分开，实际入仓后才记收益。 |
| 6·救命不是买断 | 1300 | 采购、服务和修车分别结算，信用增加但钱和责任没有消失。 |

气味、动作与语气：绷紧的牵绳、湿冷衣料、说话先看牲口的车夫；紧张后留出短暂余波。

硬边界：商队车辆不是本城突然多出的资产；不得把救到的货全当城产；工资与购粮共用342银的实际剩余额；消息传播符合两天以上的南路尺度。

采用前应查的证据：救运选择、真实损失、实物入仓与相应交易权利。

后续接续：回城者有疲劳，CH005不能全部无休继续满负荷；寒潮逼迫住房取舍。

## CH005《这一夜不许硬撑》

故事时间：D4 12:00—D5 10:00；整数刻度6000—7320。

主要改变：首轮暴雪有实际度过的结果，主角舍弃资产并兑现不强迫龙透支的约定。

主动选择与代价：优先人和可休息的伙伴，放弃可售木料及私人屋舍，不把所有损失算成敌人破坏。

核心压力：棚顶、暖屋与疲惫的救运队不能全部兼顾；热量不等于安全空间。

开场要求：从暴雪将要压到哪一处生活现场开始，不以例行汇总前四章开场。

| 场景 | 汉字预算 | 场景作用 |
|---|---:|---|
| 1·雪压到了哪里 | 1100 | 让天气作用于具体空间与人，不临时改变世界规则。 |
| 2·刚回来的人 | 1700 | 照顾疲惫、冻伤与队伍实际出勤，不能把人当无限劳力。 |
| 3·哪间屋子放掉 | 1800 | 选择牺牲私人和商业资产，保留屋舍失去后的实际影响。 |
| 4·赫穆自己作的决定 | 1700 | 允许龙在安全范围内自愿帮忙，不把善意变成无限补火。 |
| 5·轮到别人带班 | 1500 | 伊恩第一次必须接受别人的安排，不亲自完成所有抢救。 |
| 6·天亮以后 | 1200 | 有人睡着、有人数损失、有人仍不满意；只兑现这轮寒潮，不宣称整冬已安全。 |

气味、动作与语气：风停后的耳鸣、热水与湿衣、被迫挤在一起的克制幽默；给重大行动足够余波。

硬边界：龙的每三日至少一休与日上限保持；伤损、消耗、房屋损毁保留；不突然让税官知道城内每个细节；采用前必须连读CH001—CH004实际冻结全文及CH005完整候选。

采用前应查的证据：真实选择、救援后状态、财物损失和有限兑现。

后续接续：CH006处理龙的出入口和日常边界，CH007材料标准，CH008公共热与商业收益。
