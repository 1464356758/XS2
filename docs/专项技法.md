# V4.3 按缺陷调用的专项技法

本文件供单GPT按需读，不要求每章跑完所有技法。主要判断放进既有任务书与发布前报告，不再制造多套真相源。冻结旧章只读，方案面向尚未定稿内容。

## 一、让故事持续发动

书名、简介和题材给出的承诺，要落实成具体事件、选择、损失、关系变化或答案。重复提到卖点不算兑现；小兑现不等于大谜团必须立刻揭晓。新章承接上章留给读者的具体问题，不能章末制造危险、下章无代价化解。

近期3—5章写清因果，远期保留终局条件和关键依赖。各卷承担不同任务，别按总章数平均分配。阶段结果必须改变后续条件，不依靠清零旧胜利、突然换规则或新反派无限扩容。

对立方有自己的目标、资源、消息来源、行动成本与误判。检查主角造成变化之后，谁会察觉、谁利益受损、谁会主动应对。对立方可以是亲友或机构中的人，不自动等于坏人；不要求它每章露面。

## 二、信息怎样进入正文

把作者真相、各人物知情、读者已见证据分开。设定在影响人物选择时进入，信息来自观察、行动、对话、试验或有立场的材料。不把重要规则留到解决危机时才临时补出。

世界观术语多少是诊断线索，不机械规定每场最多几个。读者不一定要知道全部历史，但应能理解当前危险、目标、可行办法和代价。悬疑有意隐藏答案，不等于行动因果可以省略。

书信、账本、碑文、报告和证词都有写作者、受众、目的及认知限制。材料里的说法与客观事实分开记录；一份新材料最好改变人物决定，而非只解释另一份材料。家庭、人际题材尤其避免手续挤占关系变化。

## 三、人物、对白与节奏

对话前检查双方各想拿到什么、不能直说什么、能提供或扣住什么。看谁提问、打断、回避、转移话题，结束时谁的选择改变。潜台词可以用沉默和行动呈现；不要每句话都故作含糊。

叙述者语言与角色声音分开。人物差异来自立场、经历、表达与回避方式，不只靠每人一句口头禅。保留本书原创、作者认可的短样本，场景或阶段变化时重新校准；样本不锁死所有句长和标点。

重要事件之后检查反应、权衡和决定。紧急场景可以压缩，重大损失可以留出消化。允许阶段真赢、温暖与日常，不为持续紧张强加灾难；余波应带向新的决定，不变成反复总结。

人物可以改变信念、因错误选择滑落，也可以坚持信念改变别人。重要变化要有压力和选择支撑，不要求每章“终于明白”，不要求所有配角完整成长。配角也有自己的生活，但不靠大量背景介绍挤占当前故事。

## 四、卡住时的两种工具

**保持终点，比较走法。** 只在重要转折、明显重复或因果卡住时，为未写章节提出2—3条路径。固定硬事实和必要终点，比较主动性、代价、解题办法；不是换地点或换道具。终点本身不成立就先指出矛盾，不硬凑。

**从正文反推。** 先提取真正发生的场景、选择与结果，再看原计划。不能从“应该发生”推定“已经写出”。只提到了不算做到了，材料清单变长也不自动等于情节推进。

## 五、修文与借鉴

先定位缺陷，再调用对白、动作、视角、转场、情绪、开头或结尾专项；优先最小修改。功能标注与改稿建议保存在旁注或报告，不插进正式正文。允许无标签的过渡与细节，不按钩子密度机械删改。

参考资料只提炼“条件—安排—体验—失败条件”的机制卡，再为本书重新建立人物动机、事件因果和代价。不复制角色组合、剧情顺序或独特表达，不以某位作者文风为整书仿写目标。

不采用固定粗口、无用细节配额、故意打乱结构、每段固定长短句、按检测分数保证人写等规则。没有真实平台数据时，不生成精确留存、签约概率和收入结论。
