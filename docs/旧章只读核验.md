# 日更连载的旧章只读核验

核验日期：2026-10-28（北京时间）。系统源版本：[86a457607a709a3902b70fa48bf60f69353dc899](https://github.com/1464356758/xiaishuo-ZUOZONG/commit/86a457607a709a3902b70fa48bf60f69353dc899)。本轮只维护系统，没有生成正文或更改小说状态。

## 必须保持的规则

- 尚未采用的当前目标章，可在原任务内局部修订，最多三轮。
- adopt后立即冻结正文、标题及章后事实记录；是否登记平台发布不改变冻结边界。
- edit、repair、revalidate、再次adopt、改变canon重释过去均不能修改冻结章。相同正文和记录的幂等重试只返回既有结果，不写入新版本。
- 回看和审读必须在当前章采用前完成；旧错用incident保留原章证据，面向未来处理，不能事后改旧章凑一致。
- 中断恢复保持原目标与修订次数；reopen只重开完稿流程，不解冻既有章。

## 本轮发现与修复

原有工具会核对采用文件哈希及冻结清单，也会拒绝正常状态下的旧章改稿。但临时合成测试复现：将serialization.enabled错误关闭后，verify_files跳过冻结检查，旧章edit候选可被登记。

现改为：只要配置声明连载，或状态中存在serialization，就必须核对冻结状态。关闭开关、丢失状态或清单不完整立即停止；不自动退回迁移改稿模式，不重建清单。旧工程明确未启用连载、也没有冻结状态时保留原迁移路径，不能据此称已获得连载保护。删除全部历史证据或管理员直接改Git历史不属于工具能绝对阻止的范围。

新增合成回归覆盖：冻结开关异常、状态/清单丢失、四种旧章修订尝试及文件不变、源文件被改后拒绝续写、只修当前候选、reopen不解冻、每日恢复和完成流程遇到异常冻结时停止。所有测试使用临时目录，不写真实小说。初始化包同步包含本次加固和核验说明。
