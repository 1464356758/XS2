# 新小说初始化母版 V4.3

本包是空系统，没有上一部小说的身份、进度、正文或选题。

1. 将包内文件复制到新GitHub仓库根目录。
2. 把新仓库链接与《启动新书.txt》发送给具备GitHub读写和代码执行能力的GPT。
3. 先选择平台，再核查规则、榜单和5—10个原创选题，等作者选择。
4. 新书默认采用即冻结，启用V4.3写作任务书、限信息审读与叙事证据检查。详见docs/写作与叙事检查.md。
5. 之后使用《每日一章指令.txt》，一次只完成一章；到期全文回看在冻结前，发布回执单独登记。
6. 网页读取正式进度；个人端可授权保存检查清单。定时任务须在GPT实际建立，不自动投稿。

已有作品先核对实际状态，不用本包覆盖。升级代码不自动追认旧章通过新检查，也不解冻旧章。
